Clean order list

Practical

Scenario: An orders list has duplicates. One order is cancelled and one late order arrives.

Task: Remove duplicates, add late order 4010, remove cancelled order 4002, print the final set, the final count and check whether order 4003 exists.

Sample output
Final orders: {4001, 4003, 4004, 4010}
Final count: 4
Order 4003 exists: True
orders = [4001, 4002, 4003, 4002, 4001, 4004]
order_set = set(orders)
order_set.add(4010)          # late order
order_set.discard(4002)      # cancelled order
print("Final orders:", order_set)
print("Final count:", len(order_set))
print("Order 4003 exists:", 4003 in order_set)
